# Paper2LaTeX Local

Local-first conversion of phone photos and image PDFs into reviewable Markdown,
LaTeX mathematics, rendered/searchable PDFs, and editable electronic diagrams.

> Status: 0.3 development release. Document OCR, direct UniMERNet formula
> refinement, conservative content routing, editable diagram exports, and a
> localhost review gate are implemented. Real handwritten diagram accuracy is
> still unverified until representative user samples are reviewed and accepted.

## Workflow

The target document may contain printed pages, handwritten pages, or both in
one batch. Each individual page is routed as printed, handwritten, or uncertain.
The conversion runs locally, preserves every original, accepts at most 50 pages,
and leaves the final state as `needs_review` until a person checks the result.

Implemented behavior includes:

- image files, naturally sorted image folders, and multi-page PDF input;
- immutable original copies with SHA-256 provenance;
- EXIF orientation normalization and 300 DPI PDF rasterization;
- conservative page-boundary rectification and local illumination normalization;
- evidence for resolution, low detail/blur, overexposure/glare, heavy shadow,
  and optional OpenCV perspective-boundary analysis;
- formula-capable MinerU VLM integration with a no-implicit-download gate;
- a Tesseract printed-text fallback that explicitly marks formula OCR unsupported;
- Markdown with LaTeX, formula crop hooks, Pandoc/XeLaTeX PDF rendering, and a
  searchable PDF generated by Tesseract and merged with pypdf;
- stable per-formula Markdown anchors, with fail-closed manual placement when a
  crop cannot be mapped to one complete math token;
- partial-failure output that retains successful pages and identifies failed pages;
- overwrite refusal and machine-readable per-page truth in `review.json`.

Formula crops from MinerU can be refined by the direct UniMERNet Base adapter.
The adapter is pinned to package `unimernet==0.2.3` and model revision
`af898d48ebb1765cd3511d88f5d5f7c92279c731`; it runs offline in a separate
Python environment and therefore cannot silently download another model.

Diagram conversion adds:

- document / flowchart / mind map / architecture routing with an `uncertain`
  result instead of a silent guess;
- OpenCV candidates for standard nodes and connectors, with Tesseract labels;
- canonical editable graph JSON as the source of truth;
- faithful-position and clean top-down `.drawio`, SVG, and PDF outputs, plus
  structural Mermaid projections (Mermaid does not preserve source coordinates);
- crossed-out candidates excluded by default but visible and restorable;
- immutable initial recognition, one mutable current state, and one confirmed
  final state in a localhost-only side-by-side review page.

## Install

Python 3.11 or newer is required. Install the small project dependencies in an
isolated environment:

```bash
uv venv .venv
uv pip install --python .venv/bin/python -e .
```

The complete current-Mac workflow also discovers these external tools:

- MinerU for formula-capable Markdown;
- Tesseract with `chi_sim`, `eng`, `osd`, and `snum` language data;
- Pandoc and XeLaTeX for `document.pdf`;
- Poppler `pdftoppm` for PDF inputs and visual QA.
- draw.io Desktop for editable diagram files and Unicode/math-preserving PDF export.

Run the capability report before converting:

```bash
.venv/bin/paper2latex engines
```

MinerU models must be reviewed and downloaded separately. The adapter sets
`MINERU_MODEL_SOURCE=local` during recognition, so a conversion cannot silently
start a model download. The installed MinerU command is launched by importing
OpenCV before MinerU; this avoids the observed duplicate OpenMP abort without
using `KMP_DUPLICATE_LIB_OK=TRUE`.

The direct UniMERNet installation used on this Mac is intentionally outside the
project environment:

```text
Python: ~/.local/share/paper2latex-local/unimernet-venv/bin/python
Model:  ~/.cache/huggingface/hub/models--wanderkid--unimernet_base/
        snapshots/af898d48ebb1765cd3511d88f5d5f7c92279c731
License: Apache-2.0
Weight: 1,300,760,949 bytes
SHA-256: 16cd0891233cfee3c11215a7b87306f160f7e7f3f52091a6253751c149a8c180
```

Set `PAPER2LATEX_UNIMERNET_PYTHON` and `PAPER2LATEX_UNIMERNET_MODEL` to use
different local installation paths. They are explicit local paths; the adapter
still runs with Hugging Face and Transformers offline modes enabled.

## Convert

```bash
.venv/bin/paper2latex convert \
  "/absolute/path/to/photos-or-input.pdf" \
  --name "calculus-notes" \
  --mode auto \
  --engine mineru
```

If automatic content routing is uncertain, rerun with an explicit route:

```bash
.venv/bin/paper2latex convert \
  "/absolute/path/to/flowchart-photo.jpg" \
  --content-type flowchart \
  --output "/absolute/path/to/flowchart-ocr"
```

The result remains a draft because heuristic semantic recognition is not human
acceptance. Open the local review page, compare the source and both layouts,
edit labels/LaTeX, edge endpoints/direction, and final Markdown, restore excluded
crossed-out content if needed, and confirm every unresolved item:

```bash
.venv/bin/paper2latex review "/absolute/path/to/flowchart-ocr"
```

Final confirmation regenerates final exports and opens `diagram/clean.drawio`
in the installed draw.io desktop app. A canonical synthetic or externally
reviewed graph JSON can be passed with `--diagram-fixture graph.json` for
deterministic acceptance and integration testing.

For printed text when the formula-capable model is unavailable:

```bash
.venv/bin/paper2latex convert \
  "/absolute/path/to/printed-pages" \
  --mode printed \
  --engine tesseract
```

The default output is `<input-name>-ocr/` next to the source. Use
`--output /absolute/path` to choose another location. Existing output paths are
never overwritten. A low-quality page stops conversion unless the operator
explicitly passes `--force-quality` after reviewing the warning.

```text
<input-name>-ocr/
├── original/
├── cleaned/
├── formula-crops/
├── exports/
├── diagram/                 # diagram tasks: faithful/clean drawio,mmd,svg,pdf
├── diagram.json             # canonical semantic graph
├── diagram-review.json
├── review.initial.json      # immutable recognition snapshot after review starts
├── review.current.json      # latest edits only; no revision history
├── review.final.json        # only after every unresolved item is confirmed
├── document.md
├── document.pdf
├── searchable.pdf
└── review.json
```

Inspect status without trusting filenames alone:

```bash
.venv/bin/paper2latex status "/absolute/path/to/input-name-ocr"
```

## Truth boundary

This repository does not claim that:

- handwriting or formula accuracy has passed a real user-photo benchmark;
- OpenCV/Tesseract candidates reconstruct arbitrary free-form diagrams;
- auto-routing certainty establishes that the selected diagram type is correct;
- a Tesseract fallback converts mathematical notation to LaTeX;
- every phone-photo perspective problem can be corrected automatically;
- `conversion_state: completed` means a person has accepted the formulas;
- availability of an engine proves that its model weights are licensed,
  downloaded, compatible, or accurate for a particular document.

For formulas, compare the generated LaTeX and its rendering against the source
crop. A structurally wrong formula is a failure even when the text looks similar.
On the supplied handwritten math photo, a single-formula crop produced
`y = \\frac{1}{x_{0}}x`; a crop containing several formulas was merged into one
prediction. That observation validates single-formula segmentation as a local
pipeline requirement, not overall accuracy.
